# SANÉLIA | The Art of Gifting

A modern, elegant, and aesthetic e-commerce landing page built for **SANÉLIA** — a premium gifting and self-care brand curated with love. 

**Live Website:** [https://sanelia.me](https://sanelia.me)

---

## Features

* **Aesthetic Glassmorphism UI/UX:** Designed with a soft-pink/rose-gold theme, smooth blur effects, and custom CSS styling.
* **Responsive Navigation:** Features a custom desktop menu and a full-screen mobile menu overlay with smooth transitions.
* **Curated Collections Grid:** Showcases premium products (like hand creams, charm necklaces, and gift boxes) with an interactive "Quick Order" functionality.
* **Client Love Notes (Testimonials):** Interactive feedback and review section featuring real customer experiences.
* **Optimized Performance:** Blazing-fast load times powered by Vite and deployed seamlessly on Vercel.

---

## Tech Stack

* **Frontend:** React.js (Vite)
* **Styling:** Tailwind CSS & Custom CSS
* **Deployment & Hosting:** Vercel
* **Domain Management:** Namecheap & Custom DNS Configuration
